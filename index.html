03 — Work

Selected projects

Deep Learning Neuroscience
EEG Signal Classification
Detecting neurological patterns in biomedical time-series data
The Problem

EEG signals are notoriously noisy, high-dimensional, and subject-variable. Identifying meaningful neurological patterns manually is slow, expert-dependent, and doesn't scale. The goal was to automate this classification using deep learning.

Approach & Outcome

Designed a deep learning pipeline to process multi-channel EEG recordings as temporal sequences. Focused on architecture choices that respect the non-stationarity of neural signals. The system learned to distinguish between distinct neurological states with meaningful accuracy — demonstrating that end-to-end learning can extract diagnostic signal without hand-engineered features.

Python PyTorch Signal Processing CNN / RNN
Reinforcement Learning
Dynamic Pricing RL Agent
Learning optimal pricing strategies from market interactions
The Problem

Pricing in dynamic markets is a sequential decision problem. Fixed rules fail to adapt; supervised models can't handle delayed feedback. Reinforcement learning is a natural fit — the agent must learn when to raise, hold, or lower prices without ever seeing the optimal policy.

Approach & Outcome

Formulated pricing as an MDP with a custom reward function balancing revenue and demand responsiveness. Trained the agent using a policy gradient method in a simulated environment calibrated to realistic elasticity curves. The agent converged to pricing policies that outperform static baselines by exploiting temporal demand patterns.

Python RL (Policy Gradient) Custom Env Simulation
Optimization CSP
AI Timetabling System
Constraint satisfaction meets evolutionary algorithms for academic scheduling
The Problem

University scheduling is a combinatorially hard problem. With dozens of courses, rooms, instructors, and hard constraints, the search space grows exponentially. Standard solvers fail at realistic scale.

Approach & Outcome

Combined Constraint Satisfaction Programming for hard-constraint pruning with Genetic Algorithms for soft-constraint optimization. The hybrid approach first eliminates infeasible regions of the search space, then evolves solutions toward minimum conflict. The resulting system generated valid, conflict-free timetables for full academic departments — handling room capacity, lecturer availability, and time window constraints simultaneously.

Python Genetic Algorithms CSP Heuristic Search
Time Series
Stock Trend Forecasting
Statistical modeling of financial time series with ARIMA
The Problem

Financial time series are non-stationary, autocorrelated, and prone to structural breaks. The challenge is not just prediction accuracy but ensuring the model is correctly specified — fitting a model that the data actually supports.

Approach & Outcome

Applied ARIMA modeling in R with careful stationarity testing (ADF, KPSS), ACF/PACF analysis for order identification, and diagnostic checking of residuals. Focused on the discipline of statistical modeling: the process of arriving at a well-fitted model rather than grid-searching for the lowest error. Results included interpretable trend components and quantified forecast uncertainty.

R ARIMA Statistical Modeling Forecasting
Systems Security
Distributed Mobile Storage System
Decentralized data architecture using idle device storage
The Problem

Cloud storage introduces centralized points of failure, privacy concerns, and provider dependency. Billions of mobile devices collectively hold terabytes of unused storage. Can this idle capacity be turned into a resilient, private, distributed storage layer?

Approach & Outcome

Designed a decentralized architecture that fragments and encrypts data across participating mobile devices, with automatic recovery mechanisms if nodes go offline. The system eliminates single-provider dependency and ensures data is never readable in transit or at rest on any single node. Built as a research prototype exploring the intersection of distributed systems and mobile computing.

Distributed Systems Encryption Mobile (Android) P2P Architecture
ML Data Mining
YouTube Trends Analysis
Extracting engagement patterns from large-scale platform data
The Problem

What actually drives video engagement at scale? Views, likes, comment velocity, and title characteristics all interact non-linearly. The goal was to move beyond correlation — to identify consistent, learnable patterns across categories and time.

Approach & Outcome

Processed and cleaned a large-scale YouTube trending dataset, performed feature engineering on metadata (title length, publish time, category), and applied clustering and classification models to segment engagement patterns. Found statistically significant differences in engagement dynamics across content categories — insights that held across multiple geographic markets in the dataset.

Python Scikit-learn Pandas Data Mining
